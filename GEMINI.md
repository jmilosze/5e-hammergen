# Project Overview
**5e-hammergen** is a character generator and campaign/rules tool for Warhammer Fantasy Roleplay (WFRP / TTRPG systems).
This project is an evolution and iteration of [wfrp-hammergen](https://github.com/jmilosze/wfrp-hammergen).
